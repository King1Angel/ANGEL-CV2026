# ANGEL-CV2026

Repositorio privado del **Curriculum Vitae Web (Edición 2026)** del **Ing. Angel Peña**.

Diseñado bajo una estética **Warm Formal** basada en una paleta de **ocre, ámbar, terracota y espresso cálido**, optimizado para lectura ejecutiva en pantalla e impresión limpia a PDF.

---

## 🎨 Paleta de Color y Diseño
- **Espresso Cálido & Roasted Cacao:** `#0f0d0b`, `#181411`
- **Ámbar Radiante & Ocre:** `#d97706`, `#b45309`, `#f59e0b`
- **Alabastro Cálido (Texto):** `#fdfaf7`
- **Tipografía:** *Instrument Serif* (titulares editoriales) + *Plus Jakarta Sans* (lectura nítida) + *JetBrains Mono* (etiquetas técnicas).

---

## 📁 Archivos
- `index.html`: Estructura completa del CV Web lista para personalizar con los datos correspondientes.

---

## 🚀 Cómo visualizarlo localmente
Puedes abrir directamente el archivo `index.html` en tu navegador o previsualizarlo en tu entorno.
